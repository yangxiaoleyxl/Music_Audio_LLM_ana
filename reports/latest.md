### 1. LatentScore: An Open-Source Toolkit for Interactive Text-Steerable Procedural Audio

- **Authors**: Prabal Gupta
- **Date / sources**: 2026-11-10 · semantic_scholar
- **Relevance**: 9 pts · Generative Music & Audio: text-to-audio; has open-source code link
- **Links**: [Paper](https://www.semanticscholar.org/paper/3b41911cf1dc268a3ef09d054f9d1333fb39d631) · [PDF](https://doi.org/10.1145/3767308.3834746) · [Code 1](https://github.com/prabal-rje/latentscore)

LatentScore is an open-source Python toolkit for interactive multimedia systems that need text-steerable procedural audio, visual metadata, and live user control. Existing neural text-to-audio systems produce opaque waveforms. We instead treat prompt-to-audio as a control problem: a prompt such as morning coffee shop resolves to synthesizer parameters that the application can inspect and edit before rendering them…
